# TEMPLATE — USING THE TODAY'S WORK TAB

Quick reference for assigning a member's daily workout through the Admin Console's Coaching Hub, in the member's intake detail view.

---

## 1. Before You Assign

- [ ] The workout you want to assign is **published** in the Workout Library (draft workouts won't appear in the picker)
- [ ] The workout actually has exercises attached to it (an empty published workout will show the member a blank session)
- [ ] You know which day of the member's plan this maps to (Week X, Day Y of their program, if they're on one of the 6 base models)

## 2. Filling Out the Assignment Form

| Field | What to put |
|---|---|
| Workout | Pick from the published list — this is the actual session the member will see |
| Date | Defaults to today; change it if you're pre-loading a future day (e.g., queuing up the whole week at once) |
| Coach note | Optional, but use it for anything specific to *this member, this day* — the workout itself is reusable across members, the note is what personalizes it. Examples: "Go lighter on squats this week, you mentioned your knee" or "Great session Monday, let's push the bench a little" |

## 3. Note Style Guidance

- Keep notes short (1–2 sentences) and specific to something the member said or you observed — a generic note ("keep it up!") adds noise without adding value.
- Reference something concrete when possible: a number from last week, a form cue you gave in person, an event they mentioned (race, vacation, etc.).
- If a note would repeat every single time (e.g., a standing modification they always need), that belongs on the **exercise's** modification field in the Workout Library instead, not re-typed as a coach note every day.

## 4. When to Flag a Modification

The exercise-level modifications (up/down/pregnancy) live on each exercise in the Workout Library and show automatically to every member assigned that workout. Use the **coach note** field instead when:
- A modification is specific to this one member, not something every member doing this workout would need
- It's temporary (a tweak for this week only, not a standing limitation)
- It references something from a recent conversation or check-in that adds context the generic modification text doesn't capture

If you find yourself writing the same coach note for the same exercise across multiple members repeatedly, that's a signal the modification belongs on the exercise itself in the Workout Library — update it there once instead of retyping it as a note each time.

## 5. After Assigning

- [ ] Check the recent-assignments history (shown right below the assignment form) to confirm it saved correctly
- [ ] If assigning a full week at once, work through each day in order so the dates and Week/Day mapping stay easy to audit later
- [ ] The member sees this immediately in their Coaching Hub's Today's Work panel — no separate "publish" step needed
