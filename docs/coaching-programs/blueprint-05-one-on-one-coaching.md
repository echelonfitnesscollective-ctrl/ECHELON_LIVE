# TRAINING CARD BLUEPRINT: 1-ON-1 COACHING

**Card copy (live on site):** "Echelon's highest-touch, most premium service: fully individualized training, direct accountability, and coaching built around your body, schedule, and goals." $399/month, application and consultation required.
**Format type:** Ongoing coaching relationship, no fixed end date. Uses the same 7 base programs as 12-Week Transformation as its starting skeleton, delivery is what makes it 1-on-1, not a separate content library.

**How this doc relates to the per-goal delivery guides:** This blueprint covers cadence, session shape, and checkpoints, the same across every goal. For how personalization actually plays out exercise-by-exercise for a specific goal (age, equipment access, injuries, exercise preferences, and so on), see the existing `02-one-on-one-coaching.md` guide inside each goal's folder in `delivery-formats/`, those decision tables are still the reference for the personalization work itself.

---

## 1. How This Actually Differs From 12-Week Transformation

Both start from the same place: a client's goal maps to one of the 7 base programs (Cutting, Bulking, Muscle, Performance, Older-Adult Wellness, Weight Loss, or a Pregnancy stage), assigned day-to-day through Today's Work in the Member Portal, same as every other coached client. The base program is not the differentiator, delivery is.

| | 12-Week Transformation | 1-on-1 Coaching |
|---|---|---|
| Duration | Fixed 12-week block, ends at a Progress Review | Ongoing, no end date, periodic checkpoints instead of a hard stop |
| In-person contact | 1x/week, shared group session | 2x/week, private, one-on-one |
| Self-directed days | Today's Work, same as 1-on-1 | Today's Work, same as 12-Week |
| Customization | Base program plus pre-built modifications (up/down, pregnancy-safe) | Base program as a starting skeleton, coach can change any exercise, load, or day live, in the room, without waiting on a pre-built modification field |
| Coach note | Written after the fact, async | Written live or immediately after each in-person session, captures what actually happened that day |

## 2. Weekly Structure

- **2 in-person sessions per week**, this is the standard cadence set at enrollment, not something that gets re-negotiated week to week without a real reason.
- **Remaining days run through Today's Work**, exactly like a 12-Week client, pulled from the client's assigned base program. This keeps the client training on the days you're not in the room with them, and keeps a full digital record of every session, not just the two you're physically present for.
- In-person sessions should generally track to what Today's Work has scheduled for that day, the coach isn't improvising from zero, they're executing and adjusting the plan already on the books, live.

## 3. In-Session Shape (45–60 min)

| Block | Time | Purpose |
|---|---|---|
| Check-In | 3–5 min | How the week's gone, sleep, stress, soreness, anything that should change today's session before it starts |
| Warm-Up | 5–8 min | Movement-prep specific to today's main lifts, not generic |
| Main Block | 30–40 min | Today's Work exercises, executed and coached live, load and technique adjusted in real time |
| Finisher / Accessory | 5–10 min | Optional, based on time and how the main block went |
| Wrap-Up | 2–3 min | What to expect on self-directed days before the next session, log the coach_note before the client leaves |

## 4. How Customization Actually Works Here

This is the real difference from every other card. On 12-Week, a coach chooses from pre-built modifications (up, down, pregnancy-safe) because the client isn't in front of them day to day. In a 1-on-1 session, the coach is standing there, so customization isn't limited to what's pre-built into the exercise library:

- If a lift isn't working for a client's leverages, joint history, or how they're feeling that day, change it on the spot, swap the exercise, adjust the rep range, change the rest, whatever the session in front of you calls for.
- The base program stays the reference point for the block as a whole (so progression logic, deload timing, and the overall arc don't get lost), but no single day is locked to it the way a 12-Week client's day is.
- Log what actually got trained (not just what was originally assigned) in the coach_note, so Today's Work stays an honest record, not just a plan that may or may not have been followed.

## 5. Checkpoints (Since There's No Fixed End Date)

12-Week has a built-in Progress Review at week 10. 1-on-1 needs the same discipline without a hard stop to force it:

- **Every 8 weeks**, run a real Progress Review: photos, how the last 8 weeks actually went, what's changing for the next 8. Same conversation structure as the 12-Week Progress Review script, just recurring instead of a one-time exit conversation.
- Use this checkpoint to confirm the client's still on the right base program, someone who started on Weight Loss may have earned a move to Muscle, goals shift over months in a way they don't over 12 weeks.

## 6. Coach Notes

- Application and consultation still gate entry, this isn't a card someone just signs up for, confirm fit (schedule, goals, whether 2x/week in-person is realistic for them) before enrolling.
- Because this client is seen twice a week in person, there's less risk of them going quiet the way an async 12-Week or Coaching Membership client can, use that face time to actually catch disengagement early, not just to coach the lift in front of you.
- Roster is intentionally limited (see the scarcity tag on the live card), don't let this cadence get diluted by overbooking, 2x/week in-person per client is the whole value proposition.
