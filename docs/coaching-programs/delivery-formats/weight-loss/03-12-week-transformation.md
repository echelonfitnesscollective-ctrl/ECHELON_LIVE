# WEIGHT LOSS IN 12-WEEK TRANSFORMATION

**Base program:** [Weight Loss: 12-Week Base Model](../../02-weight-loss-12-week.md)
**Format:** Structured coaching system delivered through the Member Portal · weekly review + shared calendar, less direct-access than 1-on-1

---

## How the base model translates here

12-Week Transformation *is* the base model's native format, the base program was written as a 12-week structured system, so this is the smallest gap between "base" and "delivered." The difference from 1-on-1 isn't the programming depth, it's the delivery cadence: Transformation runs on a weekly review rhythm through the Member Portal rather than session-by-session direct coaching, so personalization happens in batches (at enrollment, and at each weekly check-in) instead of continuously.

**Working process:**
1. Capture the full intake profile *before* enrollment, Transformation doesn't have the built-in touchpoints of 1-on-1 to catch a missed detail early.
2. Personalize the base model once at enrollment using the table below, then seed the full 12-week calendar via Program Enrollment.
3. At each weekly check-in, review adherence and any new profile changes; adjust only what needs adjusting rather than re-personalizing from scratch.

## Personalization decision table

| Intake field | What it changes in 12-Week Transformation |
|---|---|
| **Secondary goal** | Noted in the enrollment coach note so weekly reviews can flag when the secondary goal and primary goal start pulling in different directions (e.g., a muscle-building secondary goal needs a smaller deficit than pure weight loss calls for). |
| **Age** | Same adjustments as 1-on-1 (longer warm-ups, joint-friendly substitutions for older clients), set once at enrollment since Transformation doesn't re-derive the plan session to session. |
| **Training experience** | Determines which phase of the base model's periodization table the member actually starts in, a true beginner may need an unofficial "Phase 0" week of technique-only sessions before Phase 1 begins, published as a manual Week 1 override. |
| **Training days available** | Directly determines which base-model days get enrolled (Day 1, 2, 4, 5, 6 as written, or a condensed subset), this is a one-time decision at enrollment, not something Transformation adjusts week to week without a re-enrollment. |
| **Session duration** | Same logic as 1-on-1: trims or adds accessory/finisher work. Since Transformation is self-guided from the published plan, be explicit in the workout notes about what's optional if a session runs long. |
| **Equipment access** | Critical to get right at enrollment, a home-gym or bodyweight-only member needs the fully-substituted workout versions built *before* enrollment, since there's no coach standing next to them to swap an exercise live like in 1-on-1. |
| **Current activity level** | Same as 1-on-1: sedentary clients start below Phase 1 volume; note this explicitly in the enrollment coach note so the member understands why Week 1 looks lighter than the published table. |
| **Injuries, conditions, pregnancy/postpartum** | Apply the base model's built-in modification notes at enrollment. Because contact is weekly rather than continuous, err toward the more conservative modification when in doubt, there's more time between check-ins for something to go unnoticed. |
| **Medical clearance** | Anything short of full clearance should delay enrollment until resolved, or enroll at a capped, conservative version with a note to revisit at the next check-in. |
| **Exercise preferences** | Build the substitutions into the enrolled program directly, Transformation members are following a published plan largely on their own, so a disliked exercise sitting in Week 6 unaddressed is a real adherence risk, not just a minor annoyance. |
| **Sleep and stress** | A flagged sleep/stress issue at enrollment is worth a lighter Phase 1 than the base model's default, since Transformation members have less real-time coaching to catch overreach early. |
| **Biggest consistency barrier** | This should shape the weekly check-in itself, a "motivation" barrier calls for more encouragement and smaller milestones in each review; a "time" barrier calls for confirming the enrolled session length actually fits their week before Week 1 even starts. |

## Coach notes

- Because Transformation runs on weekly reviews rather than per-session coaching, the enrollment moment carries more weight than in 1-on-1, a thorough intake before hitting "Enroll in Program" prevents most mid-program surprises.
- Use the weekly check-in to re-ask the fast-changing fields (sleep/stress, consistency barrier, current activity) even if the rest of the profile stays stable, these are the fields most likely to drift over 12 weeks.
