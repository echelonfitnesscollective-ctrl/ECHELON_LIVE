# WEIGHT LOSS IN 1-ON-1 COACHING

**Base program:** [Weight Loss: 12-Week Base Model](../../02-weight-loss-12-week.md)
**Format:** Fully individualized · private sessions, direct coach access

---

## How the base model translates here

1-on-1 is where the base model stops being a template and becomes an actual plan built around one person. The base model's 3-day full-body split, walk-based cardio, and phase progression are the *starting draft*, every session, every progression rule, and every exercise choice gets filtered through that client's intake profile before it's ever assigned. This is the format the base model was written to be personalized *from*, not delivered as-is.

**Working process:**
1. Build the first 1-2 weeks directly from the base model's Phase 1 (Weeks 1-3) template.
2. Run every exercise and every day through the personalization table below *before* publishing it via Program Enrollment.
3. Adjust week-to-week based on real sessions, not just the intake snapshot, the profile is a starting point, not a locked spec.

## Personalization decision table

| Intake field | What it changes in 1-on-1 |
|---|---|
| **Secondary goal** | 1-on-1 has the room to genuinely blend goals (e.g., Weight Loss + a Performance secondary for someone training for an event), the base model's rep ranges can lean toward the secondary goal's phase table on lower-priority days. |
| **Age** | Older clients: longer warm-ups, more joint-friendly exercise selection pulled from the Older-Adult Wellness base model where it overlaps, conservative load progression. |
| **Training experience** | New clients spend longer in Phase 1 numbers regardless of the 12-week clock, technique competency gates progression, not the calendar. Advanced clients can compress or skip Phase 1. |
| **Training days available** | Fewer than 3 days: consolidate into full-body sessions every available day rather than force the 3-day split. More than 3: add the base model's optional circuit/conditioning day. |
| **Session duration** | Under 45 minutes: cut accessory work first, keep the compound lifts and one conditioning finisher. Over 60: add a second finisher or extra accessory volume. |
| **Equipment access** | Full gym: run the base model as written. Home gym/bodyweight/mobile: swap every barbell/machine movement for the closest goblet, dumbbell, band, or bodyweight equivalent, see the base model's modification-down notes on Back Squat, Bench Press, and Deadlift as the pattern to extend to every other exercise. |
| **Current activity level** | Sedentary clients start below even the base model's Phase 1 volume for the first 1-2 weeks, this is the one format with room to go slower than the template calls for. |
| **Injuries, conditions, pregnancy/postpartum** | This is where the base model's built-in modification notes (up/down/pregnancy) get applied directly and specifically, exercise by exercise, not as a general caveat. |
| **Medical clearance** | Anything short of full clearance caps starting RPE and defers any load progression until the restriction is resolved or a clinician has weighed in. |
| **Exercise preferences** | Full latitude here, 1-on-1 is the format where "I hate burpees" simply means burpees never appear in this client's plan. |
| **Sleep and stress** | Poor sleep/high stress is a direct input to weekly volume and deload timing, pull the deload week (Week 12 in the base model) forward if these signals stack up early. |
| **Biggest consistency barrier** | This should shape *how* the plan is delivered as much as *what's* in it, a "time" barrier means shorter, denser sessions over longer ones; a "motivation" barrier means more frequent check-ins and smaller weekly wins to track. |

## Coach notes

- Re-check the profile every 3-4 weeks, not just at intake, activity level, stress, and even goals shift over a real 12-week relationship.
- The base model's periodization table (Phase 1→2→3→Deload) still applies as the default progression skeleton; personalization changes *what* fills each phase, not *whether* the phases exist.
