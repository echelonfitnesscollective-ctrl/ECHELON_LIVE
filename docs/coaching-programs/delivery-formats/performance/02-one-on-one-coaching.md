# PERFORMANCE IN 1-ON-1 COACHING

**Base program:** [Performance — 12-Week Base Model](../../05-performance-12-week.md)
**Format:** Fully individualized · private sessions, direct coach access

---

## How the base model translates here

1-on-1 is the format the Performance base model was actually written for. This is the only delivery format where the base model's core requirement — individualized load and velocity monitoring, rep by rep — is genuinely deliverable: a coach standing next to one athlete can watch jump height, sprint quality, and bar speed in real time and make the exact call the base model's progression rule demands ("cut the set the moment quality drops"). Every other format is a simplification of what happens here.

Given the higher injury-risk and skill-demand profile of this base model compared to the other five, 1-on-1 also carries the most careful intake screening of any Performance delivery format — landing mechanics, sprint mechanics, and joint/movement history all get assessed directly before any jump, sprint, or explosive lift volume is added.

**Working process:**
1. Screen movement quality directly in the first session or two — landing mechanics on a basic jump, sprint start position, overhead/pressing mechanics — before assigning any real power volume. This base model has the lowest error tolerance of the six; technique is confirmed before load or intensity is added, not assumed from the intake form alone.
2. Build the first 2-3 weeks directly from the base model's Phase 1 (Movement Prep) template.
3. Run every exercise and every day through the personalization table below before publishing it via Program Enrollment.
4. Adjust week-to-week based on real session performance (jump height, sprint times, bar speed, RPE) — the profile is a starting point, and this base model in particular is progressed by watching output quality live, not by following the calendar alone.

## Personalization decision table

| Intake field | What it changes in 1-on-1 |
|---|---|
| **Secondary goal** | 1-on-1 has room to genuinely blend goals — a Performance-primary client with a Weight Loss secondary can have conditioning finishers leaned toward a higher-volume, moderate-intensity style on lower-priority days, without compromising the power/speed days that stay true to the base model. |
| **Age** | Older clients: longer, more thorough movement-prep and warm-up blocks, conservative introduction of true plyometric loading, and closer attention to landing/deceleration mechanics before volume is added — age doesn't disqualify someone from this base model, but it raises the bar on screening. |
| **Training experience** | This is the single biggest gate in the whole program. New/beginner clients spend real, uncompressed time in Phase 1 (Movement Prep) regardless of the 12-week clock — technique competency, not the calendar, gates the move to Phase 2. Advanced clients with an established base can compress Phase 1 and move into real power volume sooner. |
| **Training days available** | Fewer than 4 days: consolidate to the two power/strength days and one conditioning day, preserving the "power trained fresh" principle over hitting every base-model day. More than 4: the optional sport-specific skill day (Day 6) gets added. |
| **Session duration** | Under 45 minutes: cut accessory work first, keep the power exercise and one strength lift — the power work itself is never cut for time, since a shortened warm-up or rushed power set is a genuine injury-risk shortcut in this base model specifically. Over 60: add sport-specific skill work or extra conditioning. |
| **Equipment access** | Full gym: run the base model close to as written. Home gym/limited equipment: swap barbell power work for dumbbell/med-ball/bodyweight jump variations — box jumps and sprints need minimal equipment and often translate well even outside a full gym; heavy trap-bar and barbell strength work is what needs the most substitution. |
| **Current activity level** | Sedentary or lightly-active clients start meaningfully below the base model's Phase 1 volume, with an extended movement-prep runway before any jump or sprint work is introduced at all — this is the base model where starting too fast has the highest cost. |
| **Injuries, conditions, pregnancy/postpartum** | Applied directly, exercise by exercise, using the base model's built-in modification notes. Per the base model, plyometric and sprint-based training is not appropriate during pregnancy — redirect to the Weight Loss base model or a personalized low-impact plan, and confirm any continued training with the client's own clinician. |
| **Medical clearance** | Anything short of full clearance caps intensity and defers all power/plyometric progression specifically until the restriction is resolved or a clinician has weighed in — this base model's power work is the first thing paused, not the last, when clearance is incomplete. |
| **Exercise preferences** | Full latitude — 1-on-1 can substitute freely among power, strength, and conditioning variations to avoid a disliked pattern, as long as the substitute still trains the same underlying quality (e.g., swapping box jumps for broad jumps, not dropping power work entirely). |
| **Sleep and stress** | A direct input to session structure, not just a note — per the base model's own coach guidance, recovery is the single biggest limiting factor here. Poor sleep or high stress is cause to convert that day's power work to a lighter technique session rather than push a fatigued nervous system through maximal-intent jumps or sprints. |
| **Biggest consistency barrier** | Shapes delivery: a "time" barrier means denser sessions (power + strength combined efficiently) over longer ones; a "motivation" barrier means more frequent benchmark retesting (jump height, sprint time) since visible performance gains are often this base model's strongest adherence driver. |

## Coach notes

- Retest key benchmarks (vertical jump, sprint time, a relevant strength number) every 3-4 weeks, not just at Week 12 — per the base model, this is both the progress signal and the tool for catching an under-recovering athlete early.
- This is the base model with the lowest error tolerance of the six — when in doubt about a client's readiness for a given week's power volume, the correct call is to hold at the current phase and confirm technique, not to advance on schedule.
- A client who isn't ready for true plyometric or sprint work belongs on the Muscle or Weight Loss base model until foundational strength and movement quality are in place — that's a legitimate, honest redirect, not a failure to deliver Performance coaching.
