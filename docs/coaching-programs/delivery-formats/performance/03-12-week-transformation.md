# PERFORMANCE IN 12-WEEK TRANSFORMATION

**Base program:** [Performance — 12-Week Base Model](../../05-performance-12-week.md)
**Format:** Structured coaching system delivered through the Member Portal · weekly review + shared calendar, less direct-access than 1-on-1

---

## How the base model translates here — an honest look

12-Week Transformation is structurally the closest match to how the Performance base model is written — a 12-week periodized calendar delivered through Program Enrollment. But be honest about the real gap: the base model's progression rule ("cut the power set the moment quality drops") depends on someone watching that quality in real time, and Transformation's weekly-review cadence can't replicate that the way 1-on-1's session-by-session coaching does. A member training alone between check-ins is making the "is my jump quality holding up" call themselves, with less real-time coaching support than the base model was designed around.

That gap is manageable, but it changes what Transformation needs to do differently from 1-on-1: more explicit, written self-monitoring instructions built into the plan, and a more conservative default on power/plyometric volume than a coach standing next to the athlete would need.

**Working process:**
1. Capture a thorough intake profile *before* enrollment, including a direct question about landing/sprint mechanics experience — Transformation doesn't have 1-on-1's early in-person screening session to catch a movement-quality red flag before real volume starts.
2. Personalize the base model once at enrollment using the table below, then seed the full 12-week calendar via Program Enrollment, with explicit written cues (not just exercise names) on what "stop this set" looks like for each power movement.
3. At each weekly check-in, review adherence, any reported drop in performance markers (jump height, sprint feel, soreness), and adjust — because contact is weekly rather than continuous, treat any reported red flag as worth acting on immediately rather than waiting for the next scheduled check-in.

## Personalization decision table

| Intake field | What it changes in 12-Week Transformation |
|---|---|
| **Secondary goal** | Noted in the enrollment coach note — a Performance-primary member with a secondary goal (e.g., Weight Loss) can have conditioning finishers leaned toward that secondary emphasis on lower-priority days without touching the power/strength days that need to stay true to the base model. |
| **Age** | Same adjustments as 1-on-1 (longer movement prep, conservative plyometric introduction), set once at enrollment and written explicitly into the plan since Transformation doesn't re-derive session by session. |
| **Training experience** | Determines which phase a member actually starts in, and — critically for this base model — whether they're a good candidate for self-guided Transformation at all. A true beginner to jumping/sprinting mechanics is often better started in 1-on-1 for the first few weeks of movement-prep coaching before transitioning to Transformation, rather than learning landing mechanics from a written plan alone. |
| **Training days available** | Directly determines which base-model days get enrolled. Because power work must stay fresh, a condensed schedule preserves full recovery before power days over cramming every day into a tight window. |
| **Session duration** | Same logic as 1-on-1: trims accessory work first, never the power exercise or its recovery periods. Be explicit in the workout notes about what's optional if a session runs long, since there's no coach present to make that call live. |
| **Equipment access** | Critical to nail at enrollment — a home-gym or bodyweight-only member needs the fully-substituted plyometric and strength variations built *before* enrollment, since there's no coach standing next to them to swap an exercise live. |
| **Current activity level** | Same as 1-on-1: sedentary/lightly-active members start with extended movement-prep and reduced volume — note this explicitly in the enrollment coach note so a lighter-looking Week 1 doesn't read as a mistake. |
| **Injuries, conditions, pregnancy/postpartum** | Apply the base model's modification notes at enrollment, erring conservative given the weekly (not continuous) contact cadence. Per the base model, plyometric/sprint work is not enrolled during pregnancy — redirect to the Weight Loss track. |
| **Medical clearance** | Anything short of full clearance delays enrollment in the power/plyometric elements specifically until resolved, or enrolls a strength-and-conditioning-only version with a note to add power work once cleared. |
| **Exercise preferences** | Build substitutions into the enrolled program directly, keeping the substitute in the same training-quality category (a disliked jump variation gets swapped for another jump variation, not dropped) — a self-guided member skipping the power block entirely in Week 6 is a real risk if it isn't addressed at enrollment. |
| **Sleep and stress** | A flagged issue at enrollment warrants a lighter default on power/plyometric volume than the base model's standard — Transformation members have less real-time coaching to catch an under-recovered session before it happens, so the written plan itself needs to build in more conservative defaults. |
| **Biggest consistency barrier** | Shapes the weekly check-in: a "motivation" barrier calls for regular benchmark retesting built into the schedule (visible gains are a strong driver here); a "time" barrier calls for confirming the enrolled session length is realistic before Week 1, since power work can't be rushed without losing the point of it. |

## Coach notes

- Because this base model has the lowest error tolerance of the six, the enrollment intake carries even more weight here than in the Weight Loss version of this guide — a movement-quality red flag missed at enrollment has real injury cost in a self-guided format.
- Use the weekly check-in to directly ask about performance-marker trends (jump height, sprint feel, soreness pattern), not just adherence — per the base model, recovery is the single biggest limiting factor here, and Transformation's weekly cadence is the main tool for catching a fatigue problem before it compounds.
- A member whose written check-ins suggest they aren't ready for self-guided power/plyometric work (uncertain landing mechanics, reported pain, inconsistent quality) is a candidate to shift into 1-on-1 for closer coaching, not a signal to push forward on the existing plan.
