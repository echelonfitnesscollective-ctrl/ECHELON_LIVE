# BULKING IN 1-ON-1 COACHING

**Base program:** [Bulking — 12-Week Base Model](../../03-bulking-12-week.md)
**Format:** Fully individualized · private sessions, direct coach access

---

## How the base model translates here

1-on-1 is where the Bulking base model is delivered the way it's actually designed to work. The base model's 4-day upper/lower split, linear load progression, and coach-selected weak-point accessory day all assume a coach tracking real numbers session to session — this is exactly what 1-on-1 provides, and exactly what a bulking phase needs more than almost any other goal, since progress here is measured in tracked load on the bar, not just adherence to a plan.

**Working process:**
1. Build the first 1-2 weeks directly from the base model's Phase 1 (Weeks 1-4) template.
2. Run every exercise, every load starting point, and the surplus itself through the personalization table below before publishing it via Program Enrollment.
3. Adjust week-to-week based on real strength numbers, trend weight, and joint feel — not just the intake snapshot. Bulking is the goal category where session-to-session coaching judgment matters most, since load progression only works if it's tracked accurately.

## Personalization decision table

| Intake field | What it changes in 1-on-1 |
|---|---|
| **Secondary goal** | 1-on-1 has the room to blend goals — a Bulking client with a Performance secondary goal can have the optional accessory day (Day 6) built around athletic movement patterns instead of pure size work, without touching the core 4-day split. |
| **Age** | Older clients: longer warm-ups before loaded compounds, more conservative load jumps on the linear progression scheme, closer attention to joint feel given the base model's higher weekly volume than a cutting phase. |
| **Training experience** | New-to-training clients rarely land straight in Bulking (the base model calls for a training base as a prerequisite) — but a client early in that base still gets a slower, more conservative version of Phase 1 loading. True intermediate/advanced lifters can run the base model close to as written, with load progression as the main personalization lever. |
| **Training days available** | Fewer than 4 days: consolidate into a 2-3 day full-body or push/pull/legs structure rather than force the 4-day split, prioritizing the primary compounds over accessories. 5-6 days: this is the goal category most likely to genuinely use the base model's optional Day 6 weak-point accessory day as written. |
| **Session duration** | Under 45 minutes: cut accessory work first, always keep the day's primary compound with full warm-up. Over 60: add accessory volume or extend the weak-point day rather than adding a whole new session. |
| **Equipment access** | Full gym: run the base model as written, including barbell squat/bench/deadlift as primary compounds. Home gym/bodyweight/mobile: substitute per the base model's own modification-down notes (goblet squat or front-foot-elevated split squat for back squat, dumbbell press for bench, trap-bar or rack pull for deadlift) — bulking with limited equipment is harder to progress cleanly, so be explicit about the loading plan for whatever equipment is actually available. |
| **Current activity level** | Confirm the client actually has the training base the program assumes — a recently sedentary client with a stated Bulking goal often needs a few weeks building work capacity before the base model's full volume is appropriate, even if they're eager to start "bulking" on day one. |
| **Injuries, conditions, pregnancy/postpartum** | Apply the base model's built-in modification notes exercise by exercise. Pregnancy is a hard redirect here, not a modification — the base model explicitly states Bulking is not an appropriate goal during pregnancy; move that conversation to Weight Loss or a maintenance-focused plan. |
| **Medical clearance** | Anything short of full clearance caps starting load and defers linear progression until resolved or a clinician has weighed in — this matters more here than in a lower-intensity goal, since the whole training model depends on adding real weight to the bar. |
| **Exercise preferences** | Full latitude — 1-on-1 is the format where a disliked compound (e.g., a client who hates conventional deadlift) simply gets swapped for the base model's stated alternative (trap-bar) as the permanent primary lift, not a rare substitution. |
| **Sleep and stress** | A direct input to whether load progression continues on schedule — the base program's linear progression rule already assumes good recovery; poor sleep or high stress is the clearest signal to hold at the current weight another week rather than push forward, and to consider pulling the deload week forward. |
| **Biggest consistency barrier** | Shapes delivery as much as content — a "time" barrier points toward the condensed full-body version above; a "motivation" barrier points toward more frequent strength-number check-ins, since visible load progression is one of the most motivating feedback loops in any goal category. |

## Coach notes

- Re-check the profile every 3-4 weeks, and re-check trend weight and waist circumference at the same cadence — bulking is the goal where "the plan on paper" and "what's actually happening to body composition" can drift apart fastest if nobody's watching both.
- The base model's periodization table (Phase 1 → 2 → 3 → Deload) is the default skeleton; personalization changes starting loads, exercise selection, and progression pace, not whether the phases exist.
- Nutrition coaching (surplus sizing, protein target) runs alongside the training plan in 1-on-1 — this is the format with the most room to actually coach both halves of the bulking equation together in real time.
