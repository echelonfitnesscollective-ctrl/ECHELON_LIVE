# BULKING IN 12-WEEK TRANSFORMATION

**Base program:** [Bulking: 12-Week Base Model](../../03-bulking-12-week.md)
**Format:** Structured coaching system delivered through the Member Portal · weekly review + shared calendar, less direct-access than 1-on-1

---

## How the base model translates here

12-Week Transformation is the base model's other native format, the base program was already written as a 12-week structured system with a clear weekly split and periodization table, so the gap between "base" and "delivered" is small here, same as it is for 1-on-1. The real difference is cadence: Transformation runs on a weekly review rhythm through the Member Portal rather than continuous coaching, so the load-progression tracking that a bulking phase depends on has to be built into the published plan and self-logged by the member between check-ins, not adjusted live set by set.

**Working process:**
1. Capture the full intake profile before enrollment, Transformation doesn't have 1-on-1's built-in touchpoints to catch a missed detail (equipment access in particular) early.
2. Personalize the base model once at enrollment using the table below, then seed the full 12-week calendar via Program Enrollment, including explicit linear-progression instructions the member can follow without a coach standing next to them.
3. At each weekly check-in, review logged loads and trend weight against the base model's 0.25-0.5% bodyweight/week target, and adjust only what needs adjusting.

## Personalization decision table

| Intake field | What it changes in 12-Week Transformation |
|---|---|
| **Secondary goal** | Noted in the enrollment coach note so weekly reviews can flag tension, e.g., a Performance secondary goal pulling the member toward more conditioning than the base model's minimal-conditioning design calls for. |
| **Age** | Same adjustments as 1-on-1 (longer warm-ups, more conservative load jumps), set once at enrollment and written directly into the published plan, since Transformation doesn't re-derive it session to session. |
| **Training experience** | Determines the starting loads seeded into Phase 1 and how explicitly the linear-progression rule needs to be spelled out, a member newer to structured progression needs the "add load only when all reps are clean" rule stated plainly in the workout notes, not assumed knowledge. |
| **Training days available** | Directly determines which base-model days get enrolled (the full 4-day split plus optional Day 6, or a condensed subset), a one-time decision at enrollment, not something adjusted week to week without a re-enrollment. |
| **Session duration** | Same logic as 1-on-1: trims or adds accessory volume. Be explicit in the workout notes about what's optional if a session runs long, since there's no coach live to make that call for the member mid-session. |
| **Equipment access** | Critical to get right at enrollment, home-gym or bodyweight-only members need the fully substituted version of the split built and published before Week 1, since bulking's core mechanism (progressively loading a lift) requires the member to know exactly what they're progressing on without a coach adjusting it live. |
| **Current activity level** | Confirm training-base readiness at enrollment; a member without a real training base gets an explicit lighter Phase 1 published, with a note explaining why Week 1 is intentionally lighter than the standard table. |
| **Injuries, conditions, pregnancy/postpartum** | Apply the base model's modification notes at enrollment, erring conservative given the weekly (not continuous) contact cadence. A pregnancy flag is a hard stop on Bulking as the enrolled program, redirect to Weight Loss or a maintenance-focused plan before enrollment, not after. |
| **Medical clearance** | Anything short of full clearance should delay enrollment in the loaded compound lifts, or enroll at a capped, lighter version with a note to revisit at the next check-in. |
| **Exercise preferences** | Build substitutions into the enrolled program directly, a disliked primary compound sitting in the plan for 12 weeks unaddressed is a real adherence and injury risk (form breakdown from low motivation) in a goal built around heavy, repeated loading. |
| **Sleep and stress** | A flagged issue at enrollment is worth a slightly slower published progression scheme than the base model's default, since Transformation members have less real-time coaching to catch overreach on load before it becomes a form or joint problem. |
| **Biggest consistency barrier** | Shapes the weekly check-in itself, a "motivation" barrier calls for celebrating visible strength-number wins each week (a genuinely strong motivator in this goal category); a "time" barrier calls for confirming the enrolled session length and day count actually fit before Week 1 starts. |

## Coach notes

- Because Transformation runs on weekly reviews, the enrollment moment carries even more weight for Bulking than it does for other goals, a bulking plan with the wrong equipment substitutions or an unclear progression rule can quietly stall a member's loading for weeks before a check-in catches it.
- Ask for logged loads (not just adherence) at every weekly check-in, trend weight alone doesn't tell you whether the gain is coming from progressive overload working as intended or just the surplus alone; the strength log is what confirms the training half of the equation is actually happening.
- Re-ask sleep/stress and current activity at each check-in even if the rest of the profile is stable, these are the fields most likely to drift and most directly tied to whether the published progression scheme is still appropriate.
