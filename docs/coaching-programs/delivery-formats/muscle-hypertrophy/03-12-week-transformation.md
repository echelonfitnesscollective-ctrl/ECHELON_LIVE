# MUSCLE (HYPERTROPHY) IN 12-WEEK TRANSFORMATION

**Base program:** [Muscle (Hypertrophy): 12-Week Base Model](../../04-muscle-hypertrophy-12-week.md)
**Format:** Structured coaching system delivered through the Member Portal · weekly review + shared calendar, less direct-access than 1-on-1

---

## How the base model translates here

12-Week Transformation is a close second to 1-on-1 as a native fit, the base model is already written as a structured 12-week system with a clear periodization table, which is exactly what Transformation is built to enroll and deliver. The real difference from 1-on-1 isn't programming depth, it's cadence: Transformation runs on weekly review through the Member Portal rather than continuous session-by-session coaching, so the base model's volume progression and mind-muscle-connection coaching have to be front-loaded into a well-built enrolled plan rather than adjusted live.

**Working process:**
1. Capture the full intake profile before enrollment, Transformation doesn't have 1-on-1's built-in touchpoints to catch a missed detail (like an equipment constraint or an exercise a client can't tolerate) early.
2. Personalize the base model once at enrollment using the table below, then seed the full 12-week calendar via Program Enrollment, including the phase-by-phase volume targets so the member can see the plan climb.
3. At each weekly check-in, review adherence, soreness/recovery signals, and any new profile changes; adjust volume or exercise selection only as needed rather than re-personalizing from scratch.

## Personalization decision table

| Intake field | What it changes in 12-Week Transformation |
|---|---|
| **Secondary goal** | Noted in the enrollment coach note so weekly reviews can flag conflicts, e.g., a fat-loss secondary goal needs a tighter calorie approach than the base model's maintenance-to-slight-surplus target, worth surfacing explicitly so the member understands the tradeoff going in. |
| **Age** | Same adjustments as 1-on-1 (joint-friendly substitutions, longer warm-ups, more conservative Phase 3 entry), set once at enrollment since Transformation doesn't re-derive the plan week to week. |
| **Training experience** | Determines which phase the member actually starts in, a client new to hypertrophy-specific training (even if generally fit) may need an extended Phase 1 published as a manual override, since mind-muscle connection and technique take real reps to build before volume ramps. |
| **Training days available** | Directly determines which base-model days get enrolled, a full 5-day split, or a condensed 3-4 day version pairing muscle groups. This is a one-time decision at enrollment; a change mid-block requires re-enrollment, so get this right up front. |
| **Session duration** | Same logic as 1-on-1: trims or adds accessory volume. Because Transformation members follow the plan largely unsupervised, be explicit in the workout notes about which exercises are optional if a session runs long, rather than leaving the member to guess. |
| **Equipment access** | Critical to get right at enrollment, a home-gym or bodyweight-only member needs the isolation-work substitutions built into the plan before Week 1, since there's no coach standing by to swap a leg extension for a band variation live. |
| **Current activity level** | Sedentary clients enroll below Phase 1's volume floor; note this explicitly in the enrollment coach note so the member understands why early weeks look lighter than the published set targets. |
| **Injuries, conditions, pregnancy/postpartum** | Apply the base model's built-in modification notes at enrollment. Because contact is weekly rather than continuous, err toward the more conservative substitution when in doubt, a joint issue that flares between check-ins has more time to compound before a coach sees it. |
| **Medical clearance** | Anything short of full clearance should delay enrollment or enroll at a capped version with Phase 3 intensity techniques explicitly withheld until clearance resolves. |
| **Exercise preferences** | Build substitutions directly into the enrolled program, a disliked exercise sitting unaddressed in Week 6 is a real adherence risk in a self-guided format, and disengagement specifically undermines the mind-muscle-connection coaching this program depends on. |
| **Sleep and stress** | A flagged sleep/stress issue at enrollment warrants a slower volume ramp than the base model's default, Transformation members have less real-time coaching to catch overreach early, so build in more conservative progression from the start. |
| **Biggest consistency barrier** | Shapes the weekly check-in, a "motivation" barrier calls for celebrating measurable wins (added reps, added sets, visible muscle-group progress) each week; a "time" barrier calls for confirming the enrolled session length and split actually fit the member's real week before Week 1 starts. |

## Coach notes

- Because Transformation runs on weekly reviews rather than per-session coaching, the enrollment moment carries even more weight here than for most goal tracks, the base model's volume progression is precise and needs to be seeded correctly, since there's no coach adjusting a set count mid-session.
- Use the weekly check-in to explicitly ask about soreness resolution and mind-muscle-connection quality ("are you feeling the target muscle working?"), not just adherence, these are the fields most predictive of whether the hypertrophy-specific stimulus is actually landing, and they're easy to miss in a portal-based check-in if not asked directly.
- Watch for Phase 3 specifically: intensity techniques are harder to coach well from a written plan than in person. Include clear written cues (e.g., "final set only, drop weight ~25% and continue to near-failure") and flag in the check-in whether the member is actually using them or skipping them because they're unclear or uncomfortable.
