# MUSCLE (HYPERTROPHY) IN 1-ON-1 COACHING

**Base program:** [Muscle (Hypertrophy): 12-Week Base Model](../../04-muscle-hypertrophy-12-week.md)
**Format:** Fully individualized · private sessions, direct coach access

---

## How the base model translates here

1-on-1 is the format the Muscle (Hypertrophy) base model was built for. Its entire value proposition, tracked weekly volume per muscle group, mind-muscle-connection coaching applied exercise by exercise, and intensity techniques introduced only once a client has earned them, requires exactly the kind of continuous, individualized attention 1-on-1 provides. This is the one format where the base model's Phase 1→2→3→Deload structure and its 10-14 → 14-18 → 16-20 sets/muscle-group progression can be run essentially as written, adjusted to the individual client's recovery and technique.

**Working process:**
1. Build the first 1-2 weeks directly from the base model's Phase 1 (Weeks 1-4) template, using the client's intake profile to set starting exercise selection and load.
2. Run every exercise and every day through the personalization table below before publishing it via Program Enrollment.
3. Track actual weekly set volume per muscle group session to session, the base model's volume progression only works if someone is counting, and in 1-on-1 that's the coach.
4. Adjust week to week based on real sessions (performance trend, soreness resolution, mind-muscle-connection quality), not just the intake snapshot.

## Personalization decision table

| Intake field | What it changes in 1-on-1 |
|---|---|
| **Secondary goal** | 1-on-1 has room to genuinely blend goals, a hypertrophy client with a performance or general-fitness secondary goal can have select accessory days lean toward that secondary goal's rep ranges without disrupting the primary muscle-group volume targets. |
| **Age** | Older clients: longer warm-ups, more joint-friendly exercise substitutions, and more conservative progression into Phase 3 intensity techniques, which carry more joint and connective-tissue demand than straight sets. |
| **Training experience** | New-to-hypertrophy-specific-training clients (even if generally fit) spend longer in Phase 1's volume base regardless of the 12-week clock, mind-muscle connection and technique competency gate progression, not the calendar. True beginners to resistance training altogether should be routed toward a foundational block before this program. Advanced clients can compress Phase 1 and enter Phase 2 volume sooner. |
| **Training days available** | Fewer than 5 days: consolidate the base model's 5-day split into 3-4 sessions using body-part pairing (e.g., combine Upper and one Push/Pull day) rather than dropping muscle groups outright, hypertrophy specifically depends on hitting each muscle group at least twice weekly, so days get merged, not skipped. More than 5: add a dedicated arm or weak-point specialization day. |
| **Session duration** | Under 45 minutes: trim to the 2-3 highest-value exercises per muscle group (compound + one isolation), cutting accessory volume first. Over 60: add accessory sets or a second exercise per muscle group to keep advancing the volume-progression numbers from the base model. |
| **Equipment access** | Full gym: run the base model as written. Home gym/bodyweight/mobile: substitute machine and cable isolation work (leg extension, cable fly, lat pulldown) with the closest dumbbell, band, or bodyweight equivalent, isolation work is harder to replicate without equipment than compound lifts, so this is the format's biggest equipment-access challenge; be direct with the client about the tradeoff. |
| **Current activity level** | Sedentary or newly-active clients start below even Phase 1's volume floor for the first 1-2 weeks, building work capacity before chasing the base model's set targets. |
| **Injuries, conditions, pregnancy/postpartum** | Apply the base model's built-in modification notes exercise by exercise (e.g., incline/standing press instead of flat press, goblet squat instead of front squat, capped RDL/hip thrust load), this is where those notes get applied specifically rather than as a general caveat. |
| **Medical clearance** | Anything short of full clearance caps starting RPE and defers Phase 3 intensity techniques until resolved or a clinician has weighed in, those techniques push closer to failure and aren't appropriate to introduce with an open medical question. |
| **Exercise preferences** | Full latitude, 1-on-1 is the format where a disliked exercise simply never appears, and since hypertrophy work depends on genuine engagement for the mind-muscle-connection piece to matter, honoring preference here isn't just comfort, it's part of what makes the technique work. |
| **Sleep and stress** | Direct input to weekly volume progression pace and deload timing, pull the deload forward if sleep/stress signals stack up before Week 12, per the recovery-management guidance in the education vault. |
| **Biggest consistency barrier** | Shapes delivery as much as content, a "time" barrier favors denser sessions (supersetting antagonist muscle groups) over longer ones; a "motivation" barrier favors more frequent check-ins and visible weekly volume/strength wins. |

## Coach notes

- Re-check the profile every 3-4 weeks, activity level, stress, and even the client's actual physique goals can shift meaningfully over a real 12-week hypertrophy block.
- The base model's periodization table still applies as the default progression skeleton; personalization changes *what* fills each phase and *how fast* volume climbs, not whether the phases exist.
- This is the format to actually run Phase 3's intensity techniques as designed, direct supervision makes drop sets and rest-pause both safer and more effective than they'd ever be in a group setting.
