# PREGNANCY IN 12-WEEK TRANSFORMATION

**Base program:** [Preconception](../../07-preconception-12-week.md) · [Prenatal](../../08-prenatal-12-week.md) · [Postpartum](../../09-postpartum-12-week.md)
**Format:** Structured coaching system delivered through the Member Portal · weekly review + shared calendar

---

## How the base models translate here, and where they don't cleanly

12-Week Transformation is built around enrolling a client into a published calendar and adjusting at weekly check-ins, that works cleanly for Preconception, which holds a steady structure for 12 weeks. It works less cleanly for Prenatal and Postpartum, both of which were written assuming session-to-session reassessment (see the [1-on-1 Coaching guide](02-one-on-one-coaching.md) for why). Transformation can still serve Prenatal and Postpartum clients well, it just needs real adjustments to how the weekly cadence gets used.

**By stage:**
- **Preconception** enrolls like any other base program, weekly check-ins are enough, nothing about this stage needs tighter contact.
- **Prenatal** can enroll into Transformation, but the weekly check-in needs to be treated as a floor, not a ceiling, encourage daily Member Portal messages for anything that changes between check-ins (new symptoms, energy shifts, provider guidance updates), don't wait for the scheduled weekly review to hear about something that happened on day two.
- **Postpartum** should **not auto-enroll into a flat 12-week calendar** the way the other six programs do. Because phase advancement is gated by symptoms, not time, a coach must manually confirm each phase transition (Phase 1 to 2, Phase 2 to 3) rather than letting the enrolled program silently progress a client to Phase 2 exercises just because Week 5 arrived on the calendar.

## Personalization decision table

| Intake field | What it changes in 12-Week Transformation |
|---|---|
| **Pregnancy stage** | Determines the base model enrolled and, critically, whether the standard "enroll once, run 12 weeks" pattern is appropriate (Preconception, Prenatal) or needs manual phase gating (Postpartum). |
| **Postpartum: provider clearance date** | Enrollment should not start before this date is confirmed, this is a harder requirement than for any other program in the system, do not enroll speculatively "for when she's cleared." |
| **Postpartum: current phase** | Only enroll the workouts for her *current, confirmed* phase, not the full 12-week Postpartum calendar in advance. Add the next phase's workouts manually once her checkpoint is actually met. |
| **Trimester, if Prenatal** | Note explicitly in the enrollment coach note which trimester she's starting in, since the base model's guidance shifts meaningfully between first and second/third trimester. |
| **Symptoms flagged at enrollment or any check-in** | For Prenatal or Postpartum, any flagged symptom should trigger an off-cycle check-in, don't wait for the next scheduled weekly review. |
| **Equipment access** | Same as any goal, build the substituted version into the enrolled plan up front, since Transformation clients follow the published plan largely on their own between sessions. |
| **Sleep and stress** | Same elevated weight as in 1-on-1, factor this into pacing more heavily for Prenatal and Postpartum than for the other goals. |
| **Biggest consistency barrier** | For Postpartum specifically, "time" is close to a default barrier given newborn care, build that expectation into the check-in cadence rather than treating a lighter week as a red flag. |

## Coach notes

- For Postpartum, resist the urge to seed the whole 12-week calendar at enrollment the way you would for every other program, seed Phase 1 only, and add each next phase manually once you've confirmed the checkpoint (no leaking, bulging, doming, or pressure) is actually met.
- Because Transformation has less real-time contact than 1-on-1, err conservative by default for Prenatal and Postpartum whenever a check-in reveals ambiguity, there's more time between reviews for something to go unaddressed than in a twice-a-week 1-on-1 relationship.
- A Prenatal or Postpartum client who needs more frequent contact than the weekly cadence can realistically provide is a good candidate to move to 1-on-1 for this window, that's a delivery-format conversation, not a sign Transformation failed her.
