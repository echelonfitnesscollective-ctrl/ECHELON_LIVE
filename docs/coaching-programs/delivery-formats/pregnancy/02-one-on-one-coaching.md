# PREGNANCY IN 1-ON-1 COACHING

**Base program:** [Preconception](../../07-preconception-12-week.md) · [Prenatal](../../08-prenatal-12-week.md) · [Postpartum](../../09-postpartum-12-week.md)
**Format:** Fully individualized · private sessions, direct coach access · see the [1-on-1 Coaching Blueprint](../../blueprint-05-one-on-one-coaching.md) for the general cadence and session shape

---

## How the base models translate here

1-on-1 is the best-fit delivery format for Prenatal and Postpartum specifically, both base programs explicitly call for continuous reassessment: the Prenatal model says the plan should "change client to client and week to week more than any other," and Postpartum's phase advancement is gated by symptoms checked in real time, not a calendar. A coach standing in the room, watching how a client actually moves that day, is exactly what those two programs were written assuming would be available.

**Working process:**
1. Confirm current stage (Preconception, Prenatal, Postpartum) and, if Postpartum, current phase and actual provider clearance date, this is a harder gate than "training experience" or "equipment access" and should be confirmed before the first session is built, not assumed from the base model.
2. Build the first session directly from that stage's base model day, then adjust live based on how the session actually goes.
3. Reassess at the *start* of every single session for Prenatal (energy, symptoms, how the last 24-48 hours went) and Postpartum (any leaking, bulging, doming, or pressure since the last session), not just at intake.

## Personalization decision table

| Intake field | What it changes in 1-on-1 |
|---|---|
| **Pregnancy stage** | Determines which base model this client is even on, this is the first decision, before any other personalization happens. |
| **Trimester, if Prenatal** | First trimester: adjust mainly for nausea and fatigue, most of the base model's exercises stay close to written. Second and third trimester: shift fully to the side-lying, seated, and standing variations, and watch balance and abdominal pressure on every set. |
| **Postpartum phase and delivery type** | A C-section delivery generally needs a longer, more conservative Phase 1 than an uncomplicated vaginal delivery, confirm with her provider's specific guidance rather than defaulting to the base model's "roughly 6 weeks" language. |
| **Symptoms that day (Prenatal or Postpartum)** | This overrides everything else in the session plan. Any leaking, bulging, doming, dizziness, or unusual pain means dropping back to the previous phase's intensity for that session, or stopping, not pushing through because "the plan says Phase 2 today." |
| **Pelvic floor PT assessment status** | If a Postpartum client has been assessed by a pelvic floor physical therapist, defer to that clearance for reintroducing running, jumping, or heavy lifting over the base model's general Phase 3 guidance. If she hasn't been assessed, stay conservative and recommend one. |
| **Training experience (pre-pregnancy)** | A client with a strong pre-pregnancy training base will often want to move faster than the base model's default pace, that instinct needs to be coached against specifically for Prenatal and Postpartum, capability before pregnancy does not override current-session symptoms. |
| **Equipment access** | Same as any goal, substitute for home-gym or bodyweight-only clients, none of the pregnancy-specific exercises require specialized equipment. |
| **Sleep and stress** | Directly shapes session intensity here more than in most other goals, poor sleep or high stress in a pregnant or postpartum client is both a fatigue signal and, for Postpartum specifically, a factor that affects pelvic floor recovery. |
| **Biggest consistency barrier** | Same general logic as other goals, but note that "time" barriers are especially real for a postpartum client managing a newborn, shorter, more flexible sessions may matter more here than almost anywhere else in the system. |

## Coach notes

- Start every Prenatal or Postpartum session with the check-in questions before touching a single exercise, this isn't a formality, it's the actual gate that determines what the session can safely include.
- Log symptom flags in the coach_note every time, even a mild one, a pattern across sessions (recurring heaviness, recurring fatigue) is easy to miss session to session but obvious once written down and reviewed.
- Never let enthusiasm, hers or yours, override a stage-appropriate ceiling. The base models are written conservatively on purpose, and 1-on-1's job is to apply them precisely, not to push past them because the client feels strong that day.
