# OLDER-ADULT WELLNESS IN 1-ON-1 COACHING

**Base program:** [Older-Adult Wellness: 12-Week Base Model](../../06-older-adult-wellness-12-week.md)
**Format:** Fully individualized · private sessions, direct coach access

---

## How the base model translates here

1-on-1 is the strongest natural fit for this base model, full stop. The base model itself is explicit that this is "the program where screen before you program matters most," and screening, real-time judgment, and continuous adjustment are exactly what 1-on-1 provides that no other format can. A client's balance level, joint history, and clearance status don't get assessed once and locked in here, they're reassessed, implicitly and explicitly, every single session.

**Working process:**
1. Complete a thorough intake before writing a single exercise, physician clearance status, joint history, balance/fall history, cardiovascular considerations, and current activity baseline all need to be known before Week 1 is built, not discovered mid-program.
2. Build the first 1-2 weeks directly from the base model's Phase 1 (Foundation, Weeks 1-4) template, applying the personalization table below to every exercise before it's assigned.
3. Adjust in real time, every session, this is the one format where a coach can genuinely respond to how a client's balance and joints feel *that day*, not just what the plan said going in.

## Personalization decision table

| Intake field | What it changes in 1-on-1 |
|---|---|
| **Delivery setting** | Fully private, one-on-one attention means every balance and mobility cue can be given hands-on and immediately corrected, this is the format where the base model's "steady and strong" coaching philosophy is easiest to actually deliver. |
| **Primary goal** | Confirms the base model's functional-strength-and-falls-prevention framing drives every session; load and intensity stay secondary to control and confidence throughout. |
| **Secondary goal** | 1-on-1 has room to layer in a secondary goal (general cardiovascular health, weight management, or recovery from a specific injury) without diluting the primary falls-prevention and function focus, the base model's structure stays intact, with minor additions around the edges. |
| **Age** | Directly shapes warm-up length (often longer than the base model's default), joint-friendly exercise selection, and how conservatively load progresses, a 58-year-old and an 88-year-old on this same base model can look quite different in practice. |
| **Training experience** | New-to-exercise clients spend longer in Foundation-phase numbers regardless of the 12-week clock; clients with a longstanding, safe training history may compress Foundation somewhat, but never skip the balance-baseline assessment that phase establishes. |
| **Training days available** | Fewer than the base model's 6 structured days: prioritize the 3 functional-strength days first, then balance work, then mobility, mobility can be assigned as simple home practice on non-session days if total availability is limited. |
| **Session duration** | Shorter sessions: keep the balance and functional-strength core, trim gentle-cardio time first. Longer sessions: add more balance-progression variety or extra mobility work, not more load. |
| **Equipment access** | Home/no-equipment clients: every base-model exercise has a bodyweight or household-object equivalent (a sturdy chair for sit-to-stand, filled water jugs for light carries), 1-on-1 is the format with the most latitude to build these substitutions carefully, exercise by exercise. |
| **Current activity level** | Sedentary clients start below even the base model's Foundation-phase volume for the first 1-2 weeks; this is normal and expected, not a sign the client needs to "catch up" quickly. |
| **Injuries, conditions** | This is where the base model's modification notes get applied specifically and individually, a confirmed joint replacement, arthritis diagnosis, or balance-affecting condition directly determines which exercise variations are used from Day 1, not adjusted after the fact. |
| **Medical clearance** | Nothing beyond the most conservative, fully-supported version of the program begins until clearance is confirmed. This is the single hardest gate in the entire delivery-format system, and 1-on-1's direct physician-communication access (with the client's consent) makes it the easiest format to actually resolve clearance questions in. |
| **Exercise preferences** | Full latitude, if a client dislikes or is anxious about a specific movement (very common with floor-to-standing transitions or single-leg work), 1-on-1 can substitute freely while still hitting the same functional pattern a different way. |
| **Sleep and stress** | Directly informs session-to-session intensity, a rough sleep night or a new medication is a same-day cue to default to a lighter, more supported session, not a reason to skip. |
| **Biggest consistency barrier** | Shapes delivery as much as content, transportation or scheduling barriers may point toward fewer, longer sessions; low confidence or fear of falling points toward extra time spent on the supported end of every progression before pushing for independence. |

## Coach notes

- Re-screen more frequently than any other population, balance level, medications, and joint status can genuinely shift month to month here in ways that rarely apply to a 25-year-old on the Muscle Hypertrophy base model. A quick check-in at the start of every session (not just every few weeks) is appropriate.
- The base model's own guidance stands: some clients will need every balance exercise fully supported for the entire 12 weeks, and that is a completely successful outcome. Do not let the 12-week structure create pressure to remove support on a schedule.
- Pain, dizziness, or shortness of breath beyond what's expected for gentle exertion is a stop-and-see-a-clinician moment, every time, 1-on-1's direct access to the client makes this the easiest format to catch early, so use that advantage.
