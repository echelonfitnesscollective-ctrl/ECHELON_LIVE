# OLDER-ADULT WELLNESS IN 12-WEEK TRANSFORMATION

**Base program:** [Older-Adult Wellness — 12-Week Base Model](../../06-older-adult-wellness-12-week.md)
**Format:** Structured coaching system delivered through the Member Portal · weekly review + shared calendar, less direct-access than 1-on-1

---

## How the base model translates here

12-Week Transformation is the base model's native structure — a 12-week periodized plan is exactly the shape the base model was written in. What changes for this population specifically is how much weight the enrollment moment carries. Because Transformation runs on a weekly review rhythm rather than continuous, session-by-session coaching, the thorough screening this base model depends on has to happen almost entirely up front — there isn't a coach standing beside the client to catch a balance issue or a joint flare-up in real time the way there is in 1-on-1 or Group Fitness.

**Working process:**
1. Complete the full intake — physician clearance, joint history, balance/fall history, cardiovascular considerations, current activity baseline — *before* enrollment. This population's screening bar is the highest in the system, and Transformation's lower-touch cadence makes getting it right at the start more important, not less.
2. Personalize the base model once at enrollment using the table below, then seed the full 12-week calendar via Program Enrollment, including every modification-down note explicitly written into the plan rather than left implicit.
3. At each weekly check-in, review functional benchmarks (chair stands, stair comfort, balance confidence), not just workout completion — and re-ask the fast-changing fields (new symptoms, medication changes, sleep) every single week, since those are the fields most likely to matter here.

## Personalization decision table

| Intake field | What it changes in 12-Week Transformation |
|---|---|
| **Delivery setting** | Self-guided from a published plan with weekly review — every modification and support option needs to be written directly into the plan itself, since there's no coach present in the moment to demonstrate it live. |
| **Primary goal** | Confirms the enrolled plan follows the base model's falls-prevention-and-function framing rather than being adjusted toward intensity or aesthetics at any point. |
| **Secondary goal** | Noted in the enrollment coach note so weekly reviews can watch for it pulling the plan away from the primary safety-first framing — a secondary performance or weight-loss goal never justifies a faster balance progression than the client's actual readiness supports. |
| **Age** | Same adjustments as 1-on-1 (longer warm-ups, more conservative default load and balance progression) — set explicitly at enrollment since Transformation doesn't re-derive the plan week to week the way 1-on-1 does session to session. |
| **Training experience** | Determines starting phase and pacing through Foundation — a true beginner to structured exercise may need extra weeks at Foundation-phase volume before Build begins, published as an explicit calendar extension rather than assumed. |
| **Training days available** | Directly determines which base-model days get enrolled; if daily mobility work can't realistically happen as a separate touchpoint, build a condensed version into the strength days rather than quietly dropping it. |
| **Session duration** | Trims gentle-cardio time first if sessions need to be shorter; be explicit in the workout notes about what's optional, since a self-guided member won't have a coach there to make that call live. |
| **Equipment access** | Critical to resolve at enrollment — home/no-equipment members need every substitution (chair-based sit-to-stand, household-object carries) built into the published plan before Week 1, since there's no coach to swap an exercise live. |
| **Current activity level** | Sedentary members start below the base model's Foundation-phase volume, noted explicitly in the enrollment coach note so the member understands why Week 1 looks lighter than the published table and doesn't feel behind. |
| **Injuries, conditions** | Apply the base model's modification notes at enrollment, and err toward the more conservative version whenever in doubt — weekly (not continuous) contact means more time for something to go unnoticed between check-ins. |
| **Medical clearance** | Anything short of full, confirmed clearance should delay enrollment until resolved. This is the format where that gate should be enforced most strictly, precisely because the lower-touch cadence means a clearance gap is harder to catch after enrollment than in 1-on-1 or Group Fitness. |
| **Exercise preferences** | Build substitutions directly into the enrolled program — a self-guided member facing a disliked or intimidating exercise (often single-leg or floor-transition work) in Week 6 with no coach present to adjust it live is a real adherence and confidence risk. |
| **Sleep and stress** | A flagged issue at enrollment supports a lighter Foundation phase than the base model's default; also worth an explicit note in the plan reminding the member that a rough week is a valid reason to repeat rather than advance a week's exercises. |
| **Biggest consistency barrier** | Shapes the weekly check-in itself — a "fear of falling" or low-confidence barrier calls for extra encouragement and explicit permission to stay supported longer; a "motivation" barrier calls for smaller, more frequent functional wins highlighted in each review. |

## Coach notes

- Because contact is weekly rather than continuous, this is the format where writing every modification explicitly into the plan matters most — "use support as needed" is not sufficient guidance for a member training alone; specify which support, for which exercises, by default.
- Weekly check-ins should track functional benchmarks (chair stands without hands, stair comfort, balance confidence rating) as the primary progress signal, with load as a distant secondary measure — consistent with how the base model itself defines progress.
- Any new symptom flagged in a weekly check-in — new pain, dizziness, a fall or near-fall, a new medication — should pause progression and prompt a direct conversation before the next week's plan is confirmed, not wait for the following check-in.
