# CUTTING IN 12-WEEK TRANSFORMATION

**Base program:** [Cutting: 12-Week Base Model](../../01-cutting-12-week.md)
**Format:** Structured coaching system delivered through the Member Portal · weekly review + shared calendar, less direct-access than 1-on-1

---

## How the base model translates here

12-Week Transformation is the Cutting base model's native format, the base program was written as a 12-week, phase-based system with a built-in deload at Week 12, so the structural gap between "base" and "delivered" is small. The real difference from 1-on-1 is cadence: Transformation runs on weekly reviews through the Member Portal rather than continuous, session-by-session coaching, which matters more for a Cutting client than for most other goals, because the base model's density-method progression rule and its muscle-loss red flags are designed to be caught quickly, and a weekly cadence catches them a week later than 1-on-1 would.

**Working process:**
1. Capture the full intake profile *before* enrollment, including a clear read on training experience, Transformation doesn't have 1-on-1's built-in touchpoints to catch a mismatch (e.g., a client without a real training base) early.
2. Personalize the base model once at enrollment using the table below, then seed the full 12-week calendar via Program Enrollment, including explicit refeed or diet-break placement if the deficit is on the aggressive end of the range.
3. At each weekly check-in, review trend weight, strength trend on main lifts, and sleep/stress, these are the fields most likely to signal an over-aggressive deficit, and Transformation's weekly rhythm is the main safety net catching them.

## Personalization decision table

| Intake field | What it changes in 12-Week Transformation |
|---|---|
| **Delivery setting** | Because contact is weekly rather than continuous, the enrollment profile has to be more complete and more conservative by default than in 1-on-1, there's more time between check-ins for an over-aggressive deficit or a training red flag to go unnoticed. |
| **Primary goal** | Confirms enrollment pulls from the Cutting base model specifically (steeper deficit, density-method progression, physique framing) rather than the Weight Loss base model, get this right at enrollment, since Transformation doesn't re-derive the plan session to session. |
| **Secondary goal** | Noted in the enrollment coach note so weekly reviews can flag tension early, e.g., a pure-strength secondary goal pulling against an aggressive deficit that's eating into performance. |
| **Age** | Same adjustments as 1-on-1 (more conservative deficit, joint-friendly substitutions for older clients), set once at enrollment since Transformation doesn't adjust the plan structure week to week without a re-enrollment. |
| **Training experience** | Gates which deficit range and which phase the member starts in. A client without a genuine intermediate+ training base should not be enrolled in the Cutting track at all, redirect to Weight Loss first; this is a harder line here than in 1-on-1, since there's no coach in the room to catch the mismatch mid-session. |
| **Training days available** | Directly determines which base-model days get enrolled, fewer than the base model's 4 lifting days means consolidating to protect compound lifts and total volume, a one-time decision at enrollment. |
| **Session duration** | Same logic as 1-on-1: trims accessory/finisher work first, protects the main lift. Be explicit in the workout notes about what's optional, since Transformation members are following the plan largely unsupervised. |
| **Equipment access** | Critical to get right at enrollment, a home-gym Cutting member needs fully-substituted workouts built before enrollment, and needs an explicit note that precise load tracking (central to the density progression rule) is harder without barbell increments. |
| **Current activity level** | Confirm an established training base rather than just general activity, a Cutting client with a real strength background but a recent activity dip should start the deficit conservatively for 1-2 weeks before applying the base model's full targets. |
| **Injuries, conditions** | Apply the base model's modification notes at enrollment, erring conservative, a cutting phase's steeper deficit reduces recovery capacity, so an unflagged or under-addressed injury has a higher cost here than in a maintenance or muscle-building program. |
| **Medical clearance** | Anything short of full clearance should delay enrollment in the Cutting track specifically until resolved, don't enroll a capped, conservative version of an aggressive cut; wait, or enroll in Weight Loss instead. |
| **Exercise preferences** | Build substitutions into the enrolled program directly, a disliked compound lift sitting unaddressed in Week 6 is a bigger adherence and muscle-retention risk in a cutting program than in most other goal tracks. |
| **Sleep and stress** | A flagged issue at enrollment is a reason to start at the standard (not aggressive) end of the deficit range and to schedule the first refeed or diet break earlier than the base model's default, Transformation members have less real-time coaching to catch overreach before it compounds. |
| **Biggest consistency barrier** | Shapes the weekly check-in itself, a "motivation" barrier calls for smaller weekly milestones and earlier refeed scheduling to manage fatigue; a "time" barrier calls for confirming the enrolled session length and day count are actually sustainable before Week 1 starts. |

## Coach notes

- Because Transformation runs on weekly reviews, the enrollment moment carries even more weight for Cutting than for other goal tracks, a thorough intake and a deliberately-placed refeed/diet-break schedule up front prevents most of the mid-program muscle-loss and adherence problems that show up in an aggressive cut.
- Re-ask sleep/stress, training performance trend, and consistency barrier every single week, not periodically, these are the fastest-moving signals in a cutting phase and the ones most likely to indicate the deficit needs adjusting before the next check-in.
