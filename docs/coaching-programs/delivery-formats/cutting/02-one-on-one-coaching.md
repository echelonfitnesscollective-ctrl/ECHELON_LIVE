# CUTTING IN 1-ON-1 COACHING

**Base program:** [Cutting: 12-Week Base Model](../../01-cutting-12-week.md)
**Format:** Fully individualized · private sessions, direct coach access

---

## How the base model translates here

1-on-1 is where a Cutting phase gets the precision it actually requires. The base model's density-method progression rule, its phase-by-phase RPE targets, and its assumption of an already-trained client only work as intended when a coach is tracking real numbers, actual working loads, actual rep performance, actual recovery signals, session to session. That's exactly what 1-on-1 provides and what no group or self-guided format can fully replicate. For a Cutting client specifically, this is the format with the least room for the base model's stimulus to get diluted on the way to the client.

**Working process:**
1. Build the first 1-2 weeks directly from the base model's Phase 1 (Weeks 1-4) template, confirming the client's true training age matches the base model's intermediate+ assumption before starting there.
2. Run every exercise, every day, and the deficit itself through the personalization table below *before* publishing it via Program Enrollment.
3. Track working loads and recovery markers every session, the density-method progression rule (cut rest before adding load once reps hit the top of range) depends on real per-session data, not a fixed calendar assumption.

## Personalization decision table

| Intake field | What it changes in 1-on-1 |
|---|---|
| **Delivery setting** | Direct, session-by-session coach access is what makes 1-on-1 the right home for the base model's tightest requirement, real-time load tracking against the density progression rule, rather than a batch or live-room adjustment model. |
| **Primary goal** | Confirms the deficit sizing and training emphasis follow the Cutting base model (muscle-preserving, physique-focused) rather than the more conservative Weight Loss base model, these are different starting templates even though both involve fat loss. |
| **Secondary goal** | 1-on-1 has the room to blend a Cutting primary with a secondary goal, e.g., a strength or event-performance secondary can shift emphasis toward heavier, lower-rep work on the days the base model allows some flexibility, without abandoning the deficit. |
| **Age** | Older clients cutting aggressively need more conservative deficit sizing and more attention to joint-friendly exercise selection than the base model assumes by default, age changes both the training and nutrition side here, not just training. |
| **Training experience** | The base model assumes intermediate+; verify this directly. A client without a genuine strength training base should not be started on the Cutting base model as written, redirect to the Weight Loss base model until a real training foundation exists, then transition to Cutting. |
| **Training days available** | Fewer than the base model's 4 lifting days: consolidate to protect the compound lifts and total weekly volume first, trim conditioning days before strength days, volume protection matters more in a cut than in most other goals. More available: the base model's conditioning finisher can be run more frequently if recovery supports it. |
| **Session duration** | Under 45 minutes: cut accessory and finisher work first, always protect the main compound lift and its working sets. Over 60: extra accessory volume is a reasonable add, since volume is one of the primary muscle-retention levers in a cut. |
| **Equipment access** | Full gym: run the base model as written. Home gym/limited equipment: swap using the base model's modification-down notes on Squat, Bench, and Deadlift as the pattern, but flag that load progression is harder to track precisely without barbell increments, which matters more here than in a hypertrophy or general fitness plan. |
| **Current activity level** | Most Cutting clients arrive with an established base; if activity has recently dropped (injury layoff, life disruption), start the deficit more conservatively than the base model's default and rebuild training capacity before applying the full aggressive-cut deficit range. |
| **Injuries, conditions** | Apply the base model's built-in modification notes (up/down/pregnancy) exercise by exercise. Because a cut already stresses recovery capacity, be more conservative than usual with any flagged injury, an aggressive deficit reduces the body's ability to manage additional joint stress. |
| **Medical clearance** | Anything short of full clearance caps both starting RPE and how aggressive the deficit can be, an unresolved medical flag and an aggressive cut should not be run at the same time. |
| **Exercise preferences** | Full latitude, swap freely, but flag if a disliked exercise is one of the base model's primary compound lifts (bench, squat, deadlift), since those carry more of the muscle-retention signal than accessory work does. |
| **Sleep and stress** | Directly shapes deficit sizing, not just training volume, poor sleep or high stress is a reason to start at the standard (not aggressive) end of the deficit range and build in refeeds or a diet break earlier than the base model's default timeline. |
| **Biggest consistency barrier** | Shapes how tightly the deficit and check-in cadence are structured, a "motivation" barrier calls for more frequent check-ins and earlier refeed scheduling to manage fatigue before it erodes adherence; a "time" barrier calls for protecting the main lifts within a shorter session rather than a longer one. |

## Coach notes

- Re-check the profile every 2-3 weeks rather than 3-4, a cutting phase moves faster and the red flags (strength decline, sleep/HR drift, stalled progress) covered in the deficit-sizing education content need closer tracking than a general weight-loss client requires.
- The base model's periodization table (Foundation → Density → Peak Push → Deload) is the default skeleton; personalization changes the deficit size, exercise selection, and check-in cadence around it, not whether the phases exist.
