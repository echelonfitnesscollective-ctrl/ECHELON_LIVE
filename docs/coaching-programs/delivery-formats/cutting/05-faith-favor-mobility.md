# CUTTING IN FAITH & FAVOR MOBILITY

**Base program:** [Cutting — 12-Week Base Model](../../01-cutting-12-week.md)
**Format:** Restorative strength-and-mobility class · see [Faith & Favor Mobility Blueprint](../../blueprint-03-faith-favor-mobility.md) for the general session shape

---

## How the base model translates here

Faith & Favor Mobility isn't where a Cutting client's primary training stimulus happens — the base model's heavy lifting days and metabolic conditioning need to live somewhere else (1-on-1, 12-Week Transformation, or VL Body Lab). What this format delivers for a Cutting client is arguably more valuable than for almost any other goal category: recovery capacity, at exactly the point in a client's training life when a steep calorie deficit is actively reducing it. A Cutting client is asking their body to lift heavy, hold onto muscle, and recover — all while under-fueled relative to maintenance. Recovery isn't a nice-to-have for that combination; it's part of what makes the deficit sustainable at all.

**Where this format fits in the picture:**
- As a **standing complement** to a primary training day — the same positioning as for any other goal, but with higher stakes, since a Cutting client's recovery buffer is already thinner than a maintenance or muscle-building client's.
- **Not** a starting point the way it can be for a beginner Weight Loss client — a Cutting client, by the base model's own audience definition, already has a training base and doesn't need this format as an on-ramp into training generally. Its value here is specifically recovery support, not entry-level access.

## Personalization decision table

| Intake field | What it changes in Faith & Favor Mobility |
|---|---|
| **Delivery setting** | The room's calm, coach-walked pace makes it a reliable place to actively manage recovery signals (sleep, stress, joint stiffness) that a Cutting client's steep deficit is putting pressure on — position it that way, not as filler. |
| **Primary goal** | A Cutting goal is a strong, specific reason to recommend this format as a scheduled weekly complement, not an optional extra — the deficit itself is the argument for prioritizing recovery capacity here. |
| **Secondary goal** | Doesn't change much about this format specifically — its value (recovery, joint health, stress regulation) supports nearly any secondary goal a Cutting client might be pairing with their primary. |
| **Age** | Older clients cutting through a primary training format benefit disproportionately from this as a standing complement — joint health and mobility directly protect their ability to keep training hard elsewhere while under-fueled. |
| **Training experience** | Not a gate here the way it is for VL Body Lab — this format's all-experience-levels design means a highly-trained Cutting client gets the same recovery value as anyone else; experience doesn't reduce the need for it. |
| **Training days available** | If total days are limited, weigh carefully whether a day here displaces a strength day the base model needs — for most Cutting clients running the base model's 6-7 day structure, this fits best as an add-on day or a swap for the base model's own Day 3 active-recovery slot, not a replacement for a lifting day. |
| **Session duration** | Fixed at 45 minutes by the room. |
| **Equipment access** | Not applicable — the room provides any props needed. |
| **Current activity level** | Less relevant as an entry consideration than for Weight Loss, since Cutting clients arrive with an established base — but a client showing early signs of under-recovery (per the metabolic-adaptation red flags) is a strong candidate to add this format mid-cut even if it wasn't in the original plan. |
| **Injuries, conditions** | This is the safest format in the lineup for a Cutting client managing an existing injury while still under deficit-driven recovery pressure — the coach still walks the room and corrects alignment, just at a calmer pace. Any sharp pain is coached as "ease off, see a clinician." |
| **Medical clearance** | Generally the most permissive format for a client with clearance restrictions, since intensity is inherently low — still confirm the specific restriction doesn't conflict with any movement in that week's flow. |
| **Exercise preferences** | Minor lever; the flow rotates weekly by design, so a disliked single movement is easy to work around. |
| **Sleep and stress** | The strongest match in the entire system for this specific combination — a Cutting client flagging poor sleep or high stress is exactly the profile this format's breathwork-paired structure is built to support, and exactly the profile most at risk of the metabolic-adaptation and muscle-loss red flags covered elsewhere in this program. |
| **Biggest consistency barrier** | If the barrier is burnout or diet fatigue partway through a long cut, this format is a legitimate, low-cost way to keep a client engaged and showing up during a scheduled refeed or diet break week, without abandoning training structure entirely. |

## Coach notes

- Frame this format for a Cutting client as active recovery infrastructure, not a lesser or optional class — pair it explicitly with the base model's Day 3 active-recovery slot or a scheduled diet-break week, where its value is highest.
- Watch for Cutting clients using this format as their *only* training during a rough patch — legitimate short-term during a scheduled recovery week, but flag it if it starts replacing the primary lifting days rather than supporting them, since that quietly undermines the muscle-retention goal the whole cut is built around.
