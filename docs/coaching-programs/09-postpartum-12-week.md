# ECHELON 12-WEEK BASE MODEL: POSTPARTUM

**Goal:** Rebuild pelvic floor and core function first, then walking capacity, then full-body strength, in that order, so the return to training protects long-term function instead of just chasing a fast return to intensity.
**Audience:** Clients who have delivered and received medical clearance to exercise from their provider.
**Format:** Phased, not a flat repeating week. Begins only once the client has actual medical clearance, not on a fixed calendar.
**Status:** Base model, genuinely phased, does not repeat like the other six. Personalize the pace, not just the exercises.

---

## 1. This Program Does Not Start on a Fixed Calendar

This program is phased, and it does not start on a fixed calendar, it starts when the client has medical clearance from her provider, typically around 6 weeks postpartum for an uncomplicated vaginal delivery and later for a C-section or any complication. Always defer to her provider's actual clearance date over any number here.

**Every client should be told directly:** healing timelines vary widely. Staying at an earlier phase longer is normal and correct for many women, not a setback.

---

## 2. Phase 1 (Roughly Weeks 1-4 Post-Clearance): Breath + Pelvic Floor

Diaphragmatic breathing, pelvic floor reconnection, and gentle pelvic tilts only, 2-3 short sessions a week, plus walking as tolerated. The goal is reconnecting to the deep core system, not burning calories or building strength yet.

## 3. Phase 2 (Roughly Weeks 5-8): Core Rebuild + Walking

Add gentle core rebuilding (heel slides, side-lying work, modified side planks) and build walking duration. Still no traditional crunches, sit-ups, planks, or heavy lifting, these can worsen diastasis recti or pelvic floor dysfunction if the deep core is not ready to manage the pressure.

## 4. Phase 3 (Roughly Weeks 9-12): Return to Strength

Gradually reintroduce full-body resistance training at light to moderate load, progressing week to week only if there is no leaking, bulging, doming, or heaviness/pressure in the pelvic floor during or after training. That symptom is the signal to stay at the current phase longer, not push through it. Running, jumping, and heavy lifting should wait until she is well into Phase 3 and ideally has been assessed for diastasis recti and pelvic floor function by a pelvic floor physical therapist.

## 5. What Sets This Program Apart

Postpartum is the only base program in the entire system that does not repeat a flat weekly pattern, it is built as three distinct phases that each unlock only when the previous one's checkpoint is met. Progression here is gated by symptoms, not by the calendar, staying at Phase 1 for six weeks instead of four is the plan working correctly, not a delay.
